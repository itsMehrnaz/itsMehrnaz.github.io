# Geek Blog

My personal blog — welcome to my world!

Notes on offensive security, systems internals, Rust, and whatever
rabbit hole I've fallen into lately. Some posts are in English, some
in Persian.

🔗 Live at: https://itsmehrnaz.github.io

## Built with

- [Astro](https://astro.build) — static site generator
- Bilingual support (Persian RTL / English LTR)
- Auto-deployed to GitHub Pages via GitHub Actions

## Running locally

\`\`\`bash
npm install
npm run dev
\`\`\`

## Adding a post

Drop a Markdown file in `src/content/blog/` with frontmatter:

\`\`\`markdown
---
title: "Post title"
description: "Short description"
pubDate: 'Jun 30 2026'
lang: en
---
\`\`\`
